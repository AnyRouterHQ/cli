Goal: route this project's LLM calls through AnyRouter.

AnyRouter is an OpenAI- and Anthropic-compatible gateway. Switching is a
config change — keep the existing SDK, just repoint the base URL and key.
Do not rewrite working code.

Step 1: Read the contract.
  Fetch the raw markdown and skim base URLs, auth header, the
  `provider/model` id format, and streaming:
    - Quickstart: https://docs.anyrouter.dev/getting-started/quickstart.md
    - llms.txt:   https://anyrouter.dev/llms.txt

Step 2: Confirm three things with me before editing.
    1. Which SDK is in use? (OpenAI, Anthropic, LangChain, Vercel AI SDK, custom)
    2. Which model id, in `provider/model` form? (e.g. openai/gpt-5.4-mini)
    3. Is the key exported as ANYROUTER_API_KEY? If not, I'll export it —
       never hardcode a key.

Step 3: Repoint the client.
  Change only the base URL and the key source; leave call sites alone.
    - OpenAI-compatible SDK   → baseURL https://anyrouter.dev/api/v1
    - Anthropic SDK / Claude  → baseURL https://anyrouter.dev/api
  Then:
    - Read the key from `ANYROUTER_API_KEY` (env, never inline).
    - Write model ids in `provider/model` form.
    - Reuse the existing client module if there is one; otherwise add a
      single small file that exports the configured client.
    - Preserve streaming and the current error handling.

Step 4: Verify, then stop.
  Add one smoke test that sends a short prompt and prints the reply, and
  run it once. Pass = it returns (or streams) text. On 401/403, check that
  `ANYROUTER_API_KEY` is set and starts with `sk-ar-`.

Reference: https://docs.anyrouter.dev/getting-started/quickstart.md
